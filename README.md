# 🎤 BATIA OS - AI TikTok Live Studio

Sistem automasi TikTok Live untuk host Malaysia. AI host yang boleh balas komen, pitch produk, main muzik dengan lirik karaoke, dan auto-greet penonton baru — semua dalam Bahasa Melayu pasar yang natural.

## ✨ Ciri-ciri Utama

### 🤖 AI Host Pintar
- **Balas komen real-time** dalam Bahasa Melayu pasar natural
- **Auto-greet penonton baru** dengan nama mereka
- **Policy firewall** — elak engagement bait & TikTok violations
- **Human approval zone** untuk komen sensitif
- **Multi-bahasa**: reply English bila komen English

### 🛍️ Shoppable Live Mode
- Auto-pitch produk ikut giliran
- Boleh pause/resume/interject
- Video loop produk customizable
- Selling points & promo code built-in

### 🎵 Sistem Muzik Lengkap
- Request lagu dari komen penonton ("lagu Kejora")
- Queue system (max 5 lagu)
- **Lirik karaoke real-time** dengan word-fill animation
- LRCLIB + Whisper fallback dengan language detection
- Per-song offset calibration (auto-save)
- Auto-duck muzik bila AI bercakap

### 🎁 Gift Overlay
- Visual burst untuk gift (🧡 Heart, 🌹 Rose, 🦁 Lion, 🌌 Galaxy)
- PC (Punch Card) counter dengan progress bar
- AI response caption
- Green screen ready untuk OBS/TikTok Studio

### 👆 Auto Tapper
- AI ajak viewer tap screen (bagi likes REAL)
- Setiap 45-90 saat, random interval
- Total counter untuk tracking
